## Evaluación

Por equipo (aprox. 3 integrantes), analizar un dataset (se recomienda usar Visium) de la página de [10x Genomics](https://www.10xgenomics.com/datasets?sort=publishedAt+DESC) 

- Qué se entrega: Reporte `.R` o `.Rmd`

- Qué se evaluea? 

  1. Reporte: 

    - Que corra sin error (poner atención en instruciones o ligas). 

    - Reporte de las conclusiones

  2. Presentación

    - Discusión de los análisis y resultados.

    - Participación oral de los participantes.


- Cómo se califica?

50% reporte, 50% presentación
